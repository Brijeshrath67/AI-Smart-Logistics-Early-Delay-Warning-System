How the Model Works

The XGBoost classifier uses gradient-boosted decision trees to predict whether a shipment will be delayed based on seven features extracted at booking time.

Input features per leg: origin city, destination city, route distance (km), live weather condition, live traffic level, carrier reliability score, and estimated travel time.

The model returns a delay probability (0–1). This is multiplied by 100 to give the "Delay Risk %" you see in the results. The overall shipment risk combines this with an SLA-based deadline score.

Live data inputs: weather is fetched from OpenWeatherMap; traffic is fetched from TomTom Flow API — both at submission time for the most accurate assessment.
